Aigenic widget

This page mounts the production widget script the same way a tenant would: a single <script src="/widget.js" data-site="…"> tag at the bottom of the page. If everything is wired up, you should see a chat bubble appear in the bottom-right corner within a second or two.

Use it

  1. Run the Next.js app: cd aigenic_app && pnpm dev
  2. Build the widget if you haven't: cd widget && pnpm build
  3. Open this file with a static server pointed at the Next.js origin so the widget can hit /api/widget/*: 
    cd aigenic && npx --yes serve -p 4173 .
    then visit http://localhost:4173/test.html.
  4. Make sure the script tag below uses a real site id from the dashboard. Click the bubble, ask a question — you should see the agent search the knowledge base and stream a reply.

Embed snippet

The same one your tenants paste into their site: 

<script src="https://aigenicapp.vercel.app/widget.js" data-site="YOUR_SITE_ID" async></script>

Locally we point the script at /widget.js so it loads from the dev server's public/ folder, and the widget infers the API origin from the script's URL (so it talks to /api/widget/* on the same host).

Replace REPLACE_WITH_REAL_SITE_ID below with a UUID from your dashboard. Without a real site id, the widget will hit /api/widget/config, get a 404, and silently render nothing (intentional — fail closed).
